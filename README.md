# Morse Drill

A Morse code trainer that uses spaced repetition. It runs entirely in the browser as a single `index.html`, with no build step.

- **Send** – see a word and key it with two keys (J / K) or a straight key (Space).
- **Receive** – hear a word and type it.
- **Words, Numbers, Sentences** – start with E, A, T (or 5, 0, 1); sentences open once all 26 letters are unlocked.

Progress is stored in the browser's localStorage.
